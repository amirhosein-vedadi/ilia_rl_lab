# ILIA Reduced velocity task

This task ports the current unitree_rl_mjlab ILIA Reduced Flat and Rough
velocity configurations into Isaac Lab.

## Control and policy interface

- 19 actions in ILIA_REDUCED_DOF_NAMES order.
- Physics timestep: 0.005 seconds.
- Decimation: 4; policy rate: 50 Hz.
- Position target: default + scale * action - encoder bias.
- Actuator delay: existing per-joint delayed implicit actuator.
- Flat observations: actor 68, critic 83.
- Rough observations: actor 255, critic 270.
- Rough height scan: 17 x 11, scale 0.2, zero height offset.
- Training episode duration: 20 seconds.
- Gait period: 0.8 seconds.
- Target sole height: 0.09 metres.

## Preserved source behavior

Encoder bias changes targets but is absent from joint-position observations.
Pushes add root-link velocity.
Swing peaks and action histories reset per environment.
Foot-height observations and rewards use world Z.
Startup randomization remains enabled in Play configurations.

## Simulator adaptations

PhysX contacts and friction are not numerically identical to MuJoCo.
Contact flags use a 1 N normal-force threshold.
Isaac contact observations contain normal contact forces.
Implicit-actuator torque penalties use Isaac's reported torque estimate.
Whole-body rigid-body angular momentum is reconstructed from link inertias
and body COM motion.
Rough terrain proportions and ranges match the source configuration,
but terrain meshes are generated by Isaac Lab.

## Resume

Training restores PPO state and command-curriculum progress.
Physics state, terrain progression, and startup randomization are recreated.
